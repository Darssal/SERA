## 行为与实现

- 未登录直接进入“今日”，任务、日程、草案、偏好和历史持久保存在独立设备数据库。账户恢复请求不阻塞本机界面。
- “我的”提供“登录并同步”，以一句“记录已保存在此设备”显示当前状态，隐藏不适用的账户安全、云端队列入口。未添加教学面板。
- 邮箱及手机号登录、注册完成返回“我的”；取消登录也直接返回“我的”。退出账户后恢复独立本机副本，不展示上一个账户的私有缓存。
- 主动登录后按稳定对象 ID 增量合并到账户，保留云端原有对象与本机原件。已有会话恢复只检查待同步状态，不自动导入。相同 ID 双向修改需要明确选择；旧本机副本不会覆盖后续云端编辑、复活云端删除或把本机缺失当作云端删除。
- 合并通过认证的只读预检后才进入账户持久队列；预检失败不产生账户操作、历史或合并收据。最终原子同步仍检查对象版本。网络响应丢失时复用原批次；同步期间新增的本机内容保持待同步。
- 合并实体修订号与服务端规则对齐，云端确认后的撤销仍有效。删除账户清理对应本机合并收据，独立设备原件保留。
- 未登录 AI、实时语音及上传备用识别通过独立设备能力接口工作，不使用共享账户，不获得账户工作区权限。AI 作业有内存保留时限、幂等、取消和设备／IP／全局上限；匿名请求接收提前限额、并发限制和超时，ASR 票据单次使用且日志脱敏。

| 连续操作 | 实际结果 |
| --- | --- |
| 首次打开 → 今日 | 无需登录或设置确认，直接显示输入与待办入口 |
| 今日 → 添加待办 → 输入 → 保存 | 回到待办列表，出现“免登录测试待办”；2 个操作按钮点击，加 1 次输入框聚焦 |

| 今日 → 我的 → 登录 → 返回 | 取消一次回到“我的”，记录保留 |

| 我的 → 账户 → 退出 | 回到可选登录的“我的” |
| 退出后 → 今日 → 收件箱 | 仅恢复本机待办，云端独有测试待办不串入本机副本 |

## 明确限制

- 本机记录随当前设备／浏览器存储保留；跨设备恢复需要主动登录并同步。
- 设备 AI 作业不作为云端账户记录持久化，服务进程重启后需从保留的本机输入明确重试。
- 本轮 AI、ASR、短信和邮件契约使用隔离替身验证，没有新增真实短信、邮件或付费 AI 请求。运行 readiness 只证明服务与配置就绪，不能据此宣称新增外部供应商端到端验收。
- 本轮只生成并运行新版 Web，没有生成新版 APK／AAB，也没有追加 Android 实机验收。
