## 验收口径

- 固定 F01–F16，不删除失败项或改变预算。功能正确、交互次数、响应性能分别判断。
- 从今日页、当前列表等自然位置开始，使用实际按钮、指针、键盘和返回。必要聚焦、确认、返回和重新点击计数；文字字数不计点击，滚动与查找另记。
- 注册、登录、SQLite、HTTP、离线数据库、同步事务和正式对象均为实际实现。AI 使用确定性供应商返回，只有初始合成数据经测试导入；正式旅程中的业务修改通过界面进行。
- 计时使用 release Web、正常动画和真实经过时间。功能日期固定为 2026-11-02、Asia/Hong_Kong；性能按实际日期。固定日期不代表真实跨午夜已验证。
- `report.passed=true` 表示该脚本的功能/故障注入断言完成，不自动表示性能达标。

## 已定位并修复

| 问题 | 改动与保留的边界 |
| --- | --- |
| 本地保存等待远端或平台附带处理 | 本地数据和待同步操作同事务持久化后即可继续；网络同步和平台更新分别排队。同步失败仍可见。 |
| 同步确认或慢 GET 覆盖后续本地编辑 | 应答时读取最新日志，仅移除已确认批次并重放后续操作；旧账户、已销毁仓储的迟到结果不再写回。 |
| 连续保存随着历史增多而明显变慢 | 历史仅保存变更实体与恢复顺序、校验摘要。保留原有 30 条记录和撤销能力，旧完整记录在下一次正常保存时压缩，待同步操作体保持幂等。 |
| 清单完成后撤销需要进入历史、或滚回列表顶部 | 固定位置显示本次撤销；恢复原对象、子项进度及被完成操作移除的未来时间块，保护后来更改。 |
| 长列表找回与恢复成本高 | 列表内搜索自动可见并聚焦，保留筛选与关键词；详情返回后继续当前上下文。 |
| 明确会议和目标保存后多余核对、结果页 | 明确会议可直接保存，仍可主动编辑；目标提交进入正式目标，避免为到达业务终点多走结果页。 |
| 离开调整页面后撤销被无关编辑阻断 | 精确撤销该次调整的时间块，保护后来无关修改；同一对象被更改、删除或原时段占用时明确拒绝。 |
| Web 独有的启动失败 | 更正随机标识生成的 JavaScript 位移溢出；增加真实 Chrome/IndexedDB 回归，错误入口使用本地字体主题。 |
| Web 账户切换期间平台回调串入新账户 | 异步每段校验用户与操作范围，旧提醒/推送结果不修改新账户状态。 |
| 最近操作被大量对话挡在长页面下方 | 历史页按对话、草案、操作切换，默认继续对话；操作列表保留原排序与撤销范围。 |
| 旧客户端回写新历史时丢失元数据 | 相同账户、相同 ID 且已知内容完全不变时保留原元数据；变化的降级写入整批拒绝，继续遵守版本和幂等校验。 |
| 原直接 HTTP 处理器的认证拒绝偶发断连 | 仅失败认证、真实 socket 的合法有界请求体执行最多 64 KiB、100 ms 总期限的丢弃。正常认证与 FastAPI 路径不增加等待。 |
