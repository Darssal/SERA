# SERA 2.0.4+6 · 对话与返回流程优化

日期：2026-10-31。本轮对应用户提出的“补充内容改成下一条消息”“AI 助手接近对话窗口”“保存后回到对应列表，避免多次返回”。

## 已落地的行为

- 助手以时间顺序呈现用户消息与 AI 回复，底部保留一行输入框。补充内容直接发送为下一条消息；只有最新建议提供核对入口，之前的建议保留为可阅读记录。
- 原文修改、手动添加和历史入口收纳到更多菜单。未发送内容自动保留，离开后重新打开仍可继续；旧会话没有消息记录时仍可读取原文和已有结果。
- 一次明确发送对应一次理解请求。失败重试保留原请求上下文与幂等标识，新的补充使用新请求；确认之前不创建业务对象。手动继续带入输入且不调用 AI。
- 新建日程保存后直接进入对应日期的日历，并使保存对象可见；新建任务进入适合的列表筛选。需要查看详情时由用户主动打开。
- 已有任务、日程和草案编辑保存返回原上下文；取消编辑保留会话，草案保存直接进入历史。结果页返回收束到主流程。
- 编辑器打开与退出针对性替换浏览器历史条目，避免连续取消、重开或编辑保存后，浏览器返回重新进入旧表单。普通页面导航维持既有行为。
- 会话新增可选 `messages` 与 `composerDraft`，补齐 Flutter 序列化、服务端校验及 API 文档，继续使用 schema 2；一次性身份凭证不进入这些字段。
- 与并行 AI 语义优化兼容：任务列表呈现真实阶段和日期范围，目标确认与失败状态显示实际生效的个人每日预算。
