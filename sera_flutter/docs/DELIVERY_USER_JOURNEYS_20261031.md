# SERA 2.0.7+9 · 连续用户旅程验收

本轮围绕轻度用户连续完成生活任务：记下来、补充、保存、执行、调整、离开后再继续。界面优先减少重复核对、无效返回和重复输入；没有用新增教学区或解释段落掩盖流程问题。

## 实际测试方式

- 两条完整浏览器旅程分别使用 390、320 宽度。每轮从空工作区开始，持续使用同一份数据；除首次启动与隔日重载外，通过可见控件完成所有操作。
- 360、430、1280 视口及 390 宽的 150% 字体补充待办与会议路径。桌面继续使用现有 430 最大内容宽度。
- 独立账户通过实际注册、登录、HTTP 接口、SQLite 与离线库验证保存、退出重开、断网冷启动、恢复网络和通知拒绝后的继续使用。
- AI 供应商使用确定性返回，测试数据与正式账号隔离。没有发送真实短信、邮件、推送或调用在线模型。辅助探针只读取 ID、请求数和保存结果，不代替用户操作。
- 55 个编号页面在 Widget 回归中检查布局；连续使用验收不以跳转到各编号页面替代。

## 已修复的问题

| 优先级 | 问题 | 最终行为与验证 |
| --- | --- | --- |
| P0 | 时间容量不足导致整个规划失败 | 保留完整任务、估时和阶段；真实可排部分形成时间块，剩余任务保持待安排。简短提醒并经用户确认继续。22 项任务、1650 分钟、两个 825 分钟阶段均保留；只调用一次规划。实际时间冲突、截止与依赖仍受检查。 |
| P1 | 删除日程后旧提示阻断下一次输入 | 删除成功回日历并清理遗留提示。连续执行删除→输入目标→生成，不再出现可见按钮点不动。 |
| P2 | 完整目标重复核对 | 条件齐全时在助手直接点击生成；不完整时保留必要补充。包含容量确认的目标创建路径由 7 次点击降为 6 次。 |
| P1 | 当前时间块和专注目标不一致 | 按当前/下一段可执行时间确定本次目标并持久保存。15 分钟块的按钮、倒计时、恢复会话一致；整项任务仍保留 75 分钟总估时。暂停不累计，结束只记录实际时长，不自动完成任务。 |
| P1 | 搜索结果被读成禁用的复选框 | 无完成回调的任务行采用可操作按钮语义；搜索打开原任务 ID，返回保留关键词。 |
| P1 | 恢复网络后仍等待周期同步 | Web online 事件唤醒现有同步，保留去重、账号隔离和周期回退。一轮前后观察为 29,463→533 毫秒，500 毫秒轮询；这是单次实测，不是稳定性能承诺。 |
| P1 | 离线状态对辅助技术不可见 | 隔离路由语义范围，实际“离线保存 · 2 项待同步”在断网及断网重开后均可读取。 |
| P1 | 离开调整结果页后无法找到撤销，旧入口可能撤错记录 | 历史中的最新调整提供“撤销这次调整”。结果页携带本次保存的 changeId；两处调用均在串行事务内再次核对 ID，保护后续修改、重复点击和版本冲突。成功直接回日历/历史列表；覆盖页面后的迟到结果不导航。历史时间按工作区时区显示，跨午夜日期正确；短记录不再固定占满弹窗。 |

## 回归与兼容

最终冻结源码全套 Flutter 测试 **674 通过、1 可选 HTTP 测试默认跳过**；该 HTTP 分支已单独连接隔离 Python/SQLite 服务执行通过。静态检查 **0 诊断**。后端 **339 通过**；Web worker/PCM **32 通过**；脚本/配置 **23 通过**；离线资源清单 **3 通过**；浏览器 online 订阅与取消 **1 通过**。调整撤销与历史时间专项 11 项已包含在 Flutter 总数中。

新增字段保持 schema 2：草案容量/确认字段可选；专注会话 targetMinutes 可选，旧记录缺少时正常读取。任务/时间块 ID、账户和已有记录不迁移重建。调整保存返回精确变更 ID，撤销继续使用既有快照与工作区版本保护。

本轮源码及产物清单、连续截图、原始日志、实际服务验证、前后对照放在交付证据包中。完整计划明确区分浏览器模拟、实际服务、Android 与真人首次使用观察。

## 仍需后续验证的边界

- 当前没有连接 Android 设备。签名 APK/AAB 的构建和静态校验不能替代键盘、系统返回、通知到达、后台计时、进程回收、系统日历及同签名升级的真机验收。
- 未进行陌生轻度用户的首次使用研究，不能将自动化通过解释为真实用户已无理解成本。
- 未验证在线 AI 的生成质量。对话中的地点保留在备注，当前理解协议未提供结构化地点字段，尚不会自动填入地点。
- 完整链覆盖 390/320；其他视口和 150% 字体只覆盖关键短链。J01–J12、E01–E14 的每个分支并非均由浏览器完整走过；短信、账户迟到回调和跨端冲突等由隔离自动化覆盖，系统能力单列未验。
- 没有完成同设备多轮性能基准；仅报告本次实际观察值。
