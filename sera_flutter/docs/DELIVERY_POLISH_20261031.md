## 页面与组件取舍

- 登录、账户和首次设置：表单与主操作优先；验证码、密码显隐、等待与错误状态一致；工作日使用可换行选项；注册同意及身份恢复保留。
- 今日、文字与语音输入：提交和手动添加各有明确动作，输入保留；离线、识别稿与同步状态按实际状态展示。
- 理解、澄清、草案和确认：仅有问题时展示补充问题；去除重复目标名、空分隔符、模型说明与纯教学区；保留约束、未知时间、待核对和实际写入范围。
- 日历、任务和目标：时间、状态与下一步优先；多段安排、依赖、检查项、备注、锁定、外部只读和撤销保留；低频执行设置折叠而不丢输入。
- 提醒、回顾、历史和搜索：缩短泛化鼓励与教学段落，使用真实日期、结果与对象入口组织信息。
- 设置：使用一致分组列表；设备日历与账户同步区分；通知权限、失败与保存反馈可见；课程演示降低权重但保持可达。

不以修改页面数量衡量完成度。已有布局能清楚承载业务时予以保留，通用组件负责稳定的间距、辅助字号、触控、加载、焦点与键盘行为。

## 数据与兼容性

继续使用 schema 2、现有 Controller、对象版本、同步事务和幂等批次。`resultEntity` 是可选字段，旧会话仍可读取；新增结果引用经过服务端形状、稳定 ID、同批实体、不可降级校验。旧导入中的合法删除痕迹仅在明确的 legacy import 中兼容，普通同步不放宽创建规则。

验证码、验证凭证、密码和“提交成功待刷新”状态不进入路由、恢复记录或日志。新页面跳转优先使用会话 ID，旧深链接继续兼容。正式数据库与旧安装的保全结果、产物哈希及最终运行状态由本轮 QA 汇总登记。

## 自动化与实际路径

最终 Flutter 全量 **502 通过、1 跳过、0 失败**，静态检查无问题；后端 **178/178**；Node **32/32**；启动私有配置及交付扫描器 **22/22**；离线清单 **3/3**。最终构建、安装与对应哈希见 [QA 汇总](qa/polish-20261031.json)。跳过项为需显式启用外部参考服务的 live reference 测试，本轮没有据此声称新的在线 AI 实证。

Flutter 渲染用例覆盖 55 个编号页面在 320、360、390、430 四个宽度的顶部与滚动后状态；10 个编号核心页面另覆盖 320 宽与 150% 字体。新增 11 项命名账户及身份状态测试覆盖 320×568、150% 字体和 260 px 键盘占位，包括错误定位、主操作、输入保留与禁止意外提交。测试先证实重置密码凭证错误停留在屏外，再修复恢复表单的首错定位，11 项专项通过。浏览器实际渲染、真实账号业务与 Android 流程各自登记，fixture 只证明布局与交互，不能替代真实接口保存。

本轮真实 Web 使用隔离数据库与临时账号，本地邮件、禁止 SMS 与付费 AI；Android 使用 MuMu1 独立 QA 包，真实账户、收件箱、专注、完成、返回登录和登录保留流程通过。布局 fixture 与正式运行库分离。
